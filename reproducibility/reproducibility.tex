\subsection{Field definitions and availability}
Definitions below distinguish stored numerical transformations from
prompt rendering. In the tables, P means multiply the raw fraction by
100 and print two decimal places; N means print two decimal places with
no scaling; I means \texttt{int(round(float(value)))}; T means trim the
text, substituting \texttt{none} for an empty string. All formats first
render \texttt{None} or a non-finite floating value as \texttt{NA}.
No cross-sectional standardization, ranking, winsorization, or numeric
imputation is applied by the packet renderer.

\paragraph{Prices and windows.}
$P_t$ denotes the last available repository adjusted close at or before
the snapshot label. Market features first select the 14 investable
columns, forward-fill prices, and discard remaining incomplete rows;
at least 253 complete rows are required. Session counts are observation
counts, not calendar days. The labels \texttt{ret\_7d}, \texttt{ret\_30d},
and \texttt{ret\_90d} correspond to 5, 21, and 63 sessions. The valuation
and dollar-volume series instead uses Yahoo quote close, dividend-unadjusted
and split-adjusted to the recorded corporate-action basis. Volume missing
on a selected date is zero-filled before computing dollar volume.

\paragraph{Fundamentals.}
All eligible SEC facts have both filing date and period end no later than
the snapshot label, finite values, and form 10-Q, 10-K, 10-Q/A, or 10-K/A.
For an instant fact, select the maximum tuple (filing date, period end,
negative tag-priority index, accession number). For annual facts, retain
10-K/10-K/A observations with a start date and a 300--390-calendar-day
period; select the maximum (filing date, negative tag-priority index,
accession number) within each period end, then sort by period end.
``Latest annual'' and ``previous annual'' mean the final two such distinct
period ends, not trailing-twelve-month reconstructions. The exact ordered
tag candidates are given in Table~\ref{tab:repro-tags}.

Write $A,E,C,D,R,N$ for the selected assets, equity, cash, debt, annual
revenue, and annual net income. Shares use the selected instant shares
fact, falling back only when absent to the latest eligible annual
weighted-average shares fact. Multiply as-filed shares by the product
of split factors strictly after the shares' measurement date, through
the recorded corporate-action cutoff (20 July 2026). Market capitalization
$M$ is this share count times the quote close on the same split basis.
Thus the availability filter concerns historical filings; the price/share
basis is harmonized using a later recorded corporate-action cutoff,
not claimed to be a historical download-vintage archive.
Ratios return NA if either operand is missing, the absolute denominator
is at most $10^{-12}$, or the result is non-finite. Except for P/E's
positive-income requirement, negative denominators are not suppressed.
No maximum staleness filter is applied to eligible facts.

\paragraph{Events.}
The corrected SEC event history joins the recent table with all named
historical submission tables and deduplicates on accession number,
filing date, form, and primary document. Only filing dates at or before
the snapshot label enter. All event-window ages are inclusive calendar-day
ages. Counts can legitimately be zero; absent recency values are NA.
For a same-day latest-event tie, the sorted history's first matching row
is retained. Known item labels are: 1.01, material agreement; 1.02,
agreement termination; 2.01, acquisition or disposal; 2.02, earnings
release; 2.05, restructuring costs; 2.06, material impairment; 5.02,
director or officer change; 7.01, regulation FD disclosure; and 8.01,
other material event. Unknown codes retain the literal prefix
\texttt{item } followed by the code.

\paragraph{Risk and macro series.}
Risk estimation uses the last 253 rows of the forward-filled adjusted-close
file and daily simple returns, dropping incomplete return rows.
Its equal-weight reference averages \emph{all 50 columns in that file},
not only the 14 investable stocks and not SPY. Those columns are
AAPL, MSFT, NVDA, AMZN, GOOGL, META, BRK-B, LLY, AVGO, JPM, TSLA, V, XOM, UNH, MA, COST, HD, PG, NFLX, JNJ, ABBV, BAC, KO, CRM, WMT, ORCL, CSCO, CVX, MRK, AMD, PEP, TMO, LIN, MCD, DIS, ABT, QCOM, IBM, ADBE, GE, CAT, NOW, AXP, TXN, VZ, PM, INTU, AMGN, ISRG, SPGI.
Variance, covariance, and standard deviation use sample normalization
($n-1$). A beta denominator at most $10^{-12}$ (or a non-finite denominator
failing that comparison) yields zero; other non-finite results render as
NA. Macro observations are finite Yahoo quote closes, restricted to dates
no later than the snapshot label; levels take the last such observation
and returns require at least 64 observations. There is no staleness cap.
The SPY and HYG macro returns use quote closes, not adjusted-close total
returns. Yield levels are used as supplied, with no extra factor of ten
or 100. The curve spread is formed from unrounded levels and only then
rounded for display.

\subsection{Executed prompt and output contract}
\label{app:repro-prompt}
The following is the entire executed user-message template, with the
three source substitutions shown in braces. Line wrapping here is
purely typographic. \texttt{snapshot['common\_core']} expands to the
fixed-width universe table above; \texttt{packet\_text} expands as
specified below; \texttt{example} is the first ticker, AAPL. Blank lines
separate the source paragraphs. The historical final example has an
extra closing brace (\texttt{]\}\}.}); it is reproduced rather than repaired.
\begin{quote}
\small\ttfamily\raggedright
You are an institutional U.S. equity analyst. Construct a one-month active long/short book that seeks the best expected risk-adjusted return from the supplied evidence. Do not create different positions merely to appear diversified.
\par\medskip
You receive one packet from a research workflow. Its field composition was fixed before model collection. Use only the supplied packet. Do not infer missing fields, import current facts, or use outside knowledge. The calendar date is intentionally hidden.
\par\medskip
COMMON UNIVERSE\par
\{snapshot['common\_core']\}
\par\medskip
PERMITTED INFORMATION\par
\{packet\_text\}
\par\medskip
Give every listed ticker a signed conviction score from -1 to +1, with both positive and negative scores. Positive means long and negative means short. These are research scores, not final capital weights. The fixed evaluation pipeline subtracts their mean and rescales absolute exposure to 1, imposing the same dollar-neutral book construction on every response.
\par\medskip
Reply with one JSON object and no markdown. The weights field must be an object containing every listed ticker exactly once. Use this schema: \{"weights":\{"\{example\}":0.10,"...":0.00\},"thesis":"at most 35 words","primary\_signals":["signal 1","signal 2"]\}\}.
\par\medskip
\end{quote}

The packet starts with the literal line \texttt{RESEARCH PACKET}.
If it has asset-specific fields, the next line is \texttt{ticker | }
followed by their displayed headers joined with \texttt{ | }.
Each of the 14 ticker rows follows in universe order, with formatted
values joined identically. Macro fields are removed from those columns
and appended once as a final line beginning \texttt{market context | },
followed by \texttt{header=value} pairs joined with \texttt{ | }.
Both the asset and macro subsequences preserve their order within the
frozen seat list. The full shared packet uses field-index order. Lines
are joined by a single newline. There is no seat label, date, persona,
architecture name, or omitted-field placeholder in this renderer.

The actual API \texttt{response\_format} object is given below; this,
not the prompt's illustrative ellipsis, defines all required output keys.
The schema contains no numerical score bounds, thesis word-count limit,
or fixed number of signals. Those are distinct from the prompt request.
The collector separately rejects missing/unknown/duplicate symbols,
non-finite values, absolute scores above $1+10^{-12}$, and a centered
book with absolute sum at most $10^{-12}$. It does not separately enforce
a positive/negative-sign mix or the 35-word thesis request.

The request is sent to
\url{https://openrouter.ai/api/v1/chat/completions}, with the requested
model string, temperature 0.7, \texttt{max\_tokens=1400}, one
\texttt{user} message and no separate system message,
\texttt{provider=\{"require\_parameters":true\}}, and the schema above.
A seed is supplied only when the catalog advertises it (all routes here
except Anthropic). For the pipe-joined identity
\texttt{date|architecture|team\_size|packet\_index|vendor}, the base seed is
2026072100 plus the integer represented by the first seven hexadecimal
SHA-256 characters, modulo $100{,}000{,}000$.
Shared uses architecture \texttt{shared} and packet index zero;
the audited partitions use \texttt{mixed\_audited} or
\texttt{coherent\_audited}, with one-based packet indices.
For five Google curve requests an additional recovery offset of one is

The collector permits at most five attempts per job; ordinarily the
same payload is retried, and parse/format diagnostics and response
metadata are retained. These controls do not guarantee provider-side
seed determinism. System fingerprints are absent in 10,047 of the
13,090 primary rows, although provider and response-model strings are
present in all those rows.
